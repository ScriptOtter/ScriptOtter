### 🌟 Проекты

#### 🎮 Steam Node
Инструмент для агрегированного управления пулом Steam-аккаунтов: разом выполняет операции, которые в обычном клиенте Steam требуют поочерёдного входа в каждый аккаунт.

**Возможности:**
- мониторинг балансов и статуса всех аккаунтов пула в едином дашборде;
- работа с Community Market — создание/снятие листингов и ордеров, массовая продажа предметов;
- массовая отправка трейдов и консолидация инвентаря на один адрес;
- управление подтверждениями Steam Mobile Authenticator;
- фарм игровых часов;
- сервисные операции: активация ваучеров, покупка Prime-статуса, разблокировка маркета.

---

#### 🔐 License Bot & License Server
Система лицензирования для собственных продуктов: Telegram-бот для продажи и выдачи лицензий + бэкенд-сервер, который проверяет и подтверждает их на стороне клиентского приложения.

**Как это устроено:**
- клиент привязывается к железу через HWID и подтверждает запрос собственной подписью;
- сервер сверяет подпись, проверяет чёрный список HWID и статус лицензии в базе, после чего выдаёт короткоживущий JWT (RS256) с привязкой к HWID;
- отдельные эндпоинты для проверки и обновления токена без повторной полной авторизации;
- Telegram-бот берёт на себя продажу лицензий, привязку к покупателю и служебные операции (активация, деактивация, проверка статуса клиента).

**Стек:** Express, TypeScript, Prisma ORM, PostgreSQL, JWT (RS256)

#### 🎵 Discord Music Bot
Discord-бот для стриминга музыки с YouTube прямо в голосовой канал.

**Возможности:**
- воспроизведение треков и плейлистов с YouTube по ссылке или запросу;
- сохранение и запоминание пользовательских плейлистов;
- управление воспроизведением: пауза, пропуск, перемотка, очередь треков.

---

#### 📦 Avito Price Parser
Парсер объявлений с Avito на базе Puppeteer с автоматической отправкой результатов в Telegram-бота.

**Возможности:**
- headless-обход страниц Avito по заданным фильтрам/категориям;
- извлечение цены, заголовка и ссылки на объявление;
- уведомления о новых/подходящих объявлениях прямо в Telegram-чат.
